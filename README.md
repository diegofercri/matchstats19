# matchstats19

React Native app for managing sports tournaments, built as my final degree project (TFG). This repository merges the app, database and documentation repositories; each folder keeps its full commit history.

| Folder | Contents |
|---|---|
| [app](app) | The app, built with Expo, React Native, TypeScript and NativeWind |
| [db](db) | PostgreSQL schema for Supabase: enums, roles and row-level security policies |
| [docs](docs) | Project report ([Markdown](docs/md/Memoria.md), [PDF](docs/pdf/Memoria.pdf)), diagrams and UI images |
